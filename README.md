<h2 align="left">Introducción</h2>
<p>Para este proyecto proponemos una solución tecnológica basada en una arquitectura en capas, integrando Java bajo el patrón MVC, MySQL para la base de datos y Flutter para la aplicación móvil Android. En este esquema, el Modelo gestiona la lógica de negocio, el Controlador procesa las peticiones y MySQL asegura un almacenamiento relacional ordenado y seguro</p>
